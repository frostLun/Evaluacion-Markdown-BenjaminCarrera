# Evaluacion-Markdown-BenjaminCarrera
## Proceso de Configuracion

1. Abri la aplicacion GitHub Desktop en mi computadora.
2. Seleccione la opcion Create a New Repository para crear un nuevo repositorio local.
3. Escribi el nombre del repositorio como Evaluacion-Markdown-NombreApellido.
4. Elegi la ubicacion donde guardar el repositorio en mi computadora.
5. Marque la opcion para crear automaticamente un archivo README.md.
6. Presione Create Repository para crear el repositorio.
7. Despues de crear el repositorio, seleccione la opcion Publish Repository.
8. Me asegure de que el repositorio estuviera configurado como Public.
9. Publique el repositorio en mi cuenta de GitHub.
10. Verifique en la pagina web de GitHub que el repositorio se encontraba visible en mi perfil.
